# 卡瓦利亚尔｜斯旺西 1–0 利物浦

#### 丢过五个以后，第一脚先从外面走

上一次斯旺西从后场直接传中路，被利物浦围住就地反击。这次法比安斯基加三中卫对前三形成 4v3，两个中场牵住对方中场，先从外侧接球、换边。中场等能面向对方球门再接，别背身收一脚把自己送进逼抢。夺回球也一样：先找外面的翼卫，或让乔丹·阿尤接住再转。球队能留一阵球，才不会一直挨攻。

#### 菲尔米诺回来，中卫不一定要跟

卡瓦利亚尔把中路的密度比作伦敦高峰期的车流。球没传到菲尔米诺，中卫守住身后，交给中场照看；球真进来才上，避免萨拉赫或马内斜跑进中卫留下的洞。己方攻上去仍留下三中卫加双中场，先把前场三人的反击接球点照顾住。制胜球来自角球：远端第一点争落，莫森接第二点射门。
