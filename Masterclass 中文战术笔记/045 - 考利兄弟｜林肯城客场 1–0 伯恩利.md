# 考利兄弟｜林肯城客场 1–0 伯恩利

#### 把比赛分成六段，每段先站得住

林肯城愿意给伯恩利控球。对手左卫是右脚，阿菲尔德也习惯进肋部，把球赶到他们左边，林肯就能少守一部分宽度。能高压时逼门将踢长，沃特福尔和拉格特对沃克斯抢第一点，其余人等落点。开场就抢出一次反击，给了全队继续这么踢的信心。巴顿后来开始控制第二点，林肯改快一点打给里德，让巴顿去他身前卡位，自己中场再去争落下来的球。

压不住就整体回收，先卡传中和门前的落点。制胜角球同样有分工：沃特福尔绕到远柱，争到以后头球摆回门前，搭档拉格特再顶。考利兄弟平时给角球套路起名字、按顺序练；这次球员临场没跑原定的那个，但第二个角球用到了两名中卫一起加练过的配合。
