# 帕杜｜纽卡斯尔 3–0 曼联

#### 放中卫传，限制卡里克

两个前锋不必一直追费迪南德和琼斯，先让卡里克拿不舒服；后面的中场收窄，堵鲁尼回到线间接球。逼得球只能走边，再由守得住的边中场帮边卫。右边用瑞恩·泰勒，也考虑到很难靠外线硬过埃弗拉，选择先稳住这一侧。

自己的进攻可以让科洛奇尼带出来、桑顿上去，也能直接考验琼斯。首球是克鲁尔长开到禁区附近，阿梅奥比争下头球，登巴·巴已经在他身后等蹭球。对手压上时直接找强点，其他前锋要提前赌第二下。卡巴耶第二球原本站着像要传中，却选择自己打进远距离任意球。
