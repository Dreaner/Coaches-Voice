# 威尔·斯蒂尔｜兰斯 0–0 巴黎圣日耳曼

兰斯从 3-5-2 起步。巴黎出球时马尔基尼奥斯会进中场，两名前锋管分开的中卫。先封里面，球到边上才一起贴，另一名前锋封回传，翼卫从内往外上抢。远侧翼卫收回给中卫多一人，避免第一拨晚了就被姆巴佩冲身后。

#### 有球时变成四人出球

一侧中卫拉边、另一侧翼卫回落，巴黎前三人面对四人，加门将是 5 打 3。接应者真有空间才找脚下做第三人，也可以给巴洛贡跑边中卫和边路之间。泽内利往拉莫斯不愿跟的外侧或线间走。巴黎少一人以后，内马尔的自由回撤反而让他们一度在中间多打少。兰斯改 4-2-3-1，两翼先保护内线，球到了边后卫脚下再围。

抢得下来还得做对最后一脚。斯蒂尔说，球队进到想要的区域后，有几次因为急着把机会兑现，传球和第一脚处理反而仓促。
