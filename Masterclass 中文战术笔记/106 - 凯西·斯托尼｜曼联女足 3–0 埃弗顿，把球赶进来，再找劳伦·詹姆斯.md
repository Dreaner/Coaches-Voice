# 凯西·斯托尼｜曼联女足 3–0 埃弗顿，把球赶进来，再找劳伦·詹姆斯

#### Funnel press：里面的人站在接球者外侧肩膀

斯托尼想逼埃弗顿的中卫和边卫把球送进中场。边锋冲出去，封掉沿边线的路；中场站在接球者外侧肩膀，等球进来就往前抢，争取直接拿下。如果对方一脚做回外面，曼联边卫得敢放掉原来盯的人往前顶，另外三人一起缩过去。细节在中场的起点：差一步只能阻止转身，先站好就可能把传球变成自己的。

#### 给詹姆斯脚下，给边锋身后

埃弗顿中卫习惯先退，劳伦·詹姆斯就回到线间要球。中卫不跟，她能转身；中卫贴过来，她也有能力用身体摆脱。边锋这时可以往身后跑。第一球是左后卫直接换到右侧，西格斯沃思发现自己传不出来，回给跟上的哈里斯，詹姆斯到门前用头改了传中的方向。第二球则是詹姆斯自己在边上甩开多人，传给加尔顿头球。斯托尼希望每次传中尽量有三人进禁区，因为她们看出埃弗顿经常只看球，没跟住横着或晚一点进来的人。
