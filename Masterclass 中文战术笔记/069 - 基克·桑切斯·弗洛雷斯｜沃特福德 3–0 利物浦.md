# 基克·桑切斯·弗洛雷斯｜沃特福德 3–0 利物浦

#### 长传不是把球还回去，先知道谁争下一脚

弗洛雷斯赛前就接受利物浦大约六成控球。利物浦前六人容易把横传、给边卫的球、背身给后腰的球变成围抢信号。沃特福德让门将戈麦斯或边卫跳过这块区域，找迪尼和伊哈洛争顶；边路安排阿布迪、胡拉多这种能留住球的人，落点下来后还能在对方半场多踢几脚，自己也能喘气。

第二球就是这个判断：中间掉了一个五五开的球，迪尼争到后没在原地再倒，直接找站在越位线附近的伊哈洛。只要球落下来时他已经准备启动，就能凭速度跑过中卫。中路用来挤掉对手的机会，抢到球后尽快离开那片区域。
