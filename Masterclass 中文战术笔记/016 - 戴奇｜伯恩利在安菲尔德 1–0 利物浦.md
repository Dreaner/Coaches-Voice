# 戴奇｜伯恩利在安菲尔德 1–0 利物浦

#### 把比赛变成二点球

利物浦开门球时，双前锋和中场敢贴上去，尽量让阿利松开长球，塔尔科夫斯基和本·米去争第一点，中场收在他们附近捡落点。利物浦短传出了第一层，就把球锁在一侧；阿诺德或范戴克有时间转移，全队马上横移。来不及就退回禁区前，保护戴奇画的 V 字区域。近侧边后卫、边前卫、中场轮流出脚，里面保持紧凑，仍留一名前锋当出口。

#### 定位球结束得比解围晚一步

伯恩利有球也会用斜长传越过中路人数劣势，找伍德做球或打高位防线身后，避开利物浦刚丢球那几米的围抢。决定比赛的一次是麦克尼尔把定位球送到后点。第一点没直接拿到，洛顿上来争解围后的球；利物浦后卫往外走的瞬间，巴恩斯反向跑进去造点。练定位球时，谁准备接第二落点和谁争第一点一样具体。
