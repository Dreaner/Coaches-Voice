# 塞蒂恩｜皇家贝蒂斯 3–0 西班牙人

#### 先横着传，把 4-4-2 移开

三中卫加哈维·加西亚负责出球，哈维站在对方双前锋背后。两个翼卫提得像边锋，洛伦牵住中卫，法比安和瓜尔达多则分别到对方双中场的两侧，布德布兹在中间找接应角度。对方两条线很窄时，先把球带到一边，再从他们横移后露出来的口传回里面。巴尔特拉把球送进线间、瓜尔达多接到能转身，是打到最后一线的关键。

丢球后的准备和传球站位要一起看。第三球丢球后是瓜尔达多先去压，抢到的是法比安。法比安带球吸住防守，等洛伦把人拉住、弗朗西斯插进空位再放球。第一下压迫的人不一定抢得到，但能让第二个人直接接着进攻。
