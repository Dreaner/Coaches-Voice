# 布鲁诺·拉热｜狼队客场 1–0 曼联

#### 转移之前，看双前锋退没退

狼队用三中卫对曼联双前锋，翼卫拉宽、波登斯和特林康接内线。对方边锋扑到外侧中卫，边卫如果不跟，翼卫就能接；边卫也上来，就找他身后或内线。打不通要换边：C 罗和卡瓦尼一起退了，可以走三中卫脚下；两人留在高位等反击，就别硬横传给他们旁边的中卫，可以先找中场绕开。

无球时不让内维斯轻易离开中路，堵直找 C 罗的地面球。三中卫保持同一条线，一人顶身后还有人补；两边尽量夹持球人，早点挡传中。后来曼联边卫上得更高，拉热换上特拉奥雷打身后。制胜球是他突到底后传中，防线都退进门前，穆蒂尼奥才有时间在外围接解围射门。
