# 波特｜厄斯特松德 2–0 加拉塔萨雷

#### 一个往深处跑，两个在线间接

波特用三中卫加门将对加拉塔萨雷 4-4-2 的双前锋。己方两个中场站在前锋背后，吸引对手中场出来；中锋把四后卫压深，塞马和戈多斯才有空间在两条线之间拿球。球如果出到外侧中卫一边，还可以用翼卫和肋部接球人，针对对方两名防守球员做 3v2。

#### 压不住门将，就换成五后卫守肋部

前场三人先拆开对方四后卫的出球联系。球给边卫，翼卫扑出去，外侧中卫接对方边锋；如果门将越过第一层把球送到边上，就集体退成五后卫，两个边前锋往里帮中场，中锋也回一点，别让双后腰横向守太远。反击时再找边前锋，跑对方已压上的边卫身后。

第一球几乎把这套有球站位走了一遍：中卫回进禁区把逼抢带出来，中场接球穿过第一道线，戈多斯接在下一道线后，再给塞马。传完的戈多斯没有停，绕外线继续跑；加上队友插向底线，塞马能等对方后卫转身退回去，再把球送进禁区。
