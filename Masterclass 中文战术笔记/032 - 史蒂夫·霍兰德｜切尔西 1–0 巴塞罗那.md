# 史蒂夫·霍兰德｜切尔西 1–0 巴塞罗那

#### 给巴萨外围，收紧梅西转身的地方

巴萨在哈维、伊涅斯塔、布斯克茨之外，还会让梅西回撤、法布雷加斯内收，中路有机会打成 5v3，同时桑切斯一直威胁身后。切尔西从 4-2-3-1 改成三中场，两个边路收进来，落成窄的 4-5-1。五中场和四后卫之间不能拉开，宁可让对手在阵前倒球。梅西尤其喜欢从右肋回接，用左脚往里做，所以切尔西左侧要有人顶住转身，旁边还要有人准备接第二下。

拉米雷斯去左边是一招两用：跟得上套边的阿尔维斯，拿球也能跑他的身后。进球是兰帕德从梅西脚下拿到球，立刻送到这一边，再由拉米雷斯横传德罗巴。切尔西也尽量不在自己控球时散得太开；霍兰德提到，一次后场出球被抢就逼出了阿什利·科尔的门线解围。
