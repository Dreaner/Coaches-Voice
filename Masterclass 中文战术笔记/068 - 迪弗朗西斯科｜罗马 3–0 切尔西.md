# 迪弗朗西斯科｜罗马 3–0 切尔西

#### 边锋要能压两个人之间，也要能进线间

切尔西用三中卫和翼卫，哲科管中间那名中卫；佩罗蒂、沙拉维起步要能挡住翼卫线路，也能根据传球扑外侧中卫，身体朝向决定能不能兼顾。斯特罗曼偏向逼后腰，纳因戈兰也压，但更常插上；德罗西留在中间清理对手两名内线攻击手接球的区域。弗洛伦齐碰阿扎尔时先引方向，别轻易伸脚。

有球时也别让边锋一直贴边。边卫或中场有人在外面，就有条件让边锋进两线之间，接球位置离门更近。佩罗蒂的进球是从外面往里带到禁区边射；沙拉维给的是跑防线身后的威胁。罗马开场就压上，切尔西反扑时再把中后场距离收紧。
