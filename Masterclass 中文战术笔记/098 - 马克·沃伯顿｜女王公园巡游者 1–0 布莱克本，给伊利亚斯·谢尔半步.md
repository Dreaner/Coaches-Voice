# 马克·沃伯顿｜女王公园巡游者 1–0 布莱克本，给伊利亚斯·谢尔半步

#### 先算留几个人，再决定翼卫能上多高

看到加拉格尔和罗斯韦尔不首发，沃伯顿更敢压。三中卫加一名后腰留守，两个翼卫、一名中场和前三人上去。左侧打起来，右边的阿多马也可以进后点。防布里尔顿·迪亚斯主要管发球的人，防线保持高位，两名中卫照看他的启动，门将随时准备出击收过顶球。只盯着前锋退会把他最喜欢冲的地带越让越大。

#### 两名中场别站平，前锋也别把谢尔堵在里面

戴克斯拉住中卫，威洛克可以绕去两侧，翼卫拉走对方翼卫。多泽尔尽量待在高一点的位置，和另一名中场不站同一条横线，谢尔就有机会在禁区前半转身接球。要是布莱克本的人出来封他，戴克斯还在身后；他们不出来，谢尔拿到半步就能做文章。关键一球前是迪基直接找到谢尔。沃伯顿还强调，周围十几码里要有人接应，传给队里脚法最好的人以后，不能只等他一个人解决。
